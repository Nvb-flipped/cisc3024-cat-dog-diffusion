# Optimization strategy for the reviewed pool

The corrected v002 noise-prediction reference scored 11/15 on each of three full development evaluations. It passed the hard checks with 4.10–4.60% memorization. Accuracy was 89.40–89.95%, FID 71.59–72.80 and recall 30.20–32.30%. The excellent tier requires accuracy ≥90%, FID ≤50 and recall ≥40%, with memorization ≤5% and every other hard condition satisfied. The hidden set and grader's seed are separate.

## Ranked work

1. **Increase useful coverage of the original pool.** This has the strongest project-specific rationale. The earlier matched 1,197-versus-1,000-crop comparison lowered memorization by 15.95 percentage points with similar FID, although both runs exceeded the cap and the class proportions differed slightly. Research also reports a greater tendency to memorize at smaller dataset sizes. A focused local pilot should target recoverable geometry errors and sources underrepresented by the current pool crops, using exact original photographs and only pool-side cues. Compare the number of visually suitable, distinct heads per reviewed candidate with the existing ranking. Keep the prior 63-crop holdout unchanged where possible. Require student approval and duplicate decisions on any additions before freezing a new manifest. Train from random initialization and compare at the same budget, sampler and seeds. A handful of new crops can establish pilot yield. A material expansion is needed to test model performance. [Gu et al., On Memorization in Diffusion Models](https://arxiv.org/abs/2310.02664)

2. **Completed inference-only test on the known v002 checkpoint.** Tested DDIM with seeded per-image trajectory noise at eta 0.35 and 0.70, using the same initial noise, 50 steps, CFG 2.5, EMA weights and generation seed 0. Both passed trained CUDA prefix, label, microbatch and RNG checks and reproduced the old output exactly at eta zero. In the full 2,000-image official runs, eta 0.35 reached 90.80% accuracy, FID 76.47, recall 34.29% and 5.15% memorization. Eta 0.70 reached 92.00% accuracy, FID 78.44, recall 31.42% and 7.60% memorization. Both exceeded the hard cap and neither advanced. Preserve eta zero and the original export. [Song et al., DDIM, sections 4.1–4.2](https://arxiv.org/html/2010.02502), [verified comparison](../experiments/v002_ddim_eta/comparison.json)

3. **Completed matched EDM redesign.** The small U-Net used the same 1,197 exact v002 crops, random initialization, 30,000-update cap, EMA, CFG 2.5, and 26 deterministic Heun noise levels. The two-crop diagnostic passed with a 98.94% probe-MSE reduction. The full seed-0 evaluations scored 5, 0 and 0 out of 15 at 24k, 28k and 30k. Memorization rose from 1.10% to 8.55% and 14.75%. The 30k checkpoint reached FID 103.11 and recall 18.14%. Keep the v002 reference. ## TA patch-size comparison

Pack the noisy full image into 64 4×4 RGB patches or 16 8×8 RGB patches. Packing is an exact spatial-to-channel permutation. Both models denoise the whole patch grid and return a 32×32 pixel prediction for the original loss and DDIM. Simple packing missed the two-crop integration gate for both sizes. A shared pixel-resolution refinement branch passed the same gate. The refinement is an architectural change. Comparing the two patch sizes controls for that shared branch, while the original pixel U-Net comparison tests the whole patch recipe. The [frozen plan](patch_grid_v002.json) fixes the reviewed v002 crops and holdout, seed, optimizer, EMA, sampling and update budget, with actual model sizes within 4% of the pixel control. The branch tests a local design motivated by published pixel diffusion architectures that combine global patch representations with high-frequency pixel refinement. [DiP, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_DiP_Taming_Diffusion_Models_in_Pixel_Space_CVPR_2026_paper.html)

The official comparison finished. At 24k and 30k the 4×4 model scored 2/15 twice, and the 8×8 model scored 1/15 twice. At 30k their FID values were 220.25 and 237.26, with recall of 0.22% and 0%. Both models generated low-diversity outputs with visible color bias. The 4×4 high-noise probe also had substantially larger guided error than the reference at timesteps 975–999. These results support retaining the v002 pixel reference and ending the tested patch recipe. The project has direct evidence for allocating the next effort to broader reviewed pool coverage.
