# Independent student checks

These are pending tasks, not completed agent-log evidence. The student must record the actual date, context, independent check, raw evidence and outcome when each happens.

1. Data: independently inspect 30 source/crop pairs, including difficult species, boundary crops and a rotated case; measure selected head widths/occupancy and compare official reconstruction.
2. Model/interface: work through a noise/reconstruction example and independently run seed, label-isolation and batch-composition probes.
3. Results: independently rerun the unchanged official evaluator, check manifest/memorization, compare report numbers to JSON and inspect sample/nearest-neighbor evidence.
